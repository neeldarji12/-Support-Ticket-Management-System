# -Support-Ticket-Management-System

A modern, responsive Support Ticket Management System built with React 19, Vite, React Router, and Lucide React.

## 🚀 Features

- **Authentication & Role-Based Access**: Role-aware session management (Admin, Agent, Employee, etc.).
- **Ticket Dashboard**: Overview of ticket statuses, priorities, key metrics, and activity.
- **Ticket Management**: Create, view, search, filter, and track support tickets.
- **Detailed Ticket View**: Status lifecycle updates, priority assignments, discussion/comments thread, and audit history.
- **Employee Management**: View team members, assigned tickets, and department roles.
- **Toast Notifications**: Interactive feedback on actions using React Toastify.
- **Modern UI**: Clean design system with responsive layouts and Lucide icons.

## 🛠️ Tech Stack

- **Frontend**: React 19, React Router v7
- **Build Tool**: Vite
- **Icons**: Lucide React
- **Notifications**: React Toastify
- **Styling**: CSS3 / Modern Flexbox & Grid

## 📦 Getting Started

### Prerequisites

- Node.js (v18 or higher recommended)
- npm or yarn

### Installation

1. **Clone the repository**:
   ```bash
   git clone https://github.com/neeldarji12/-Support-Ticket-Management-System.git
   cd -Support-Ticket-Management-System
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Start the development server**:
   ```bash
   npm run dev
   ```

4. **Build for production**:
   ```bash
   npm run build
   ```
